## PR #8 검토

원본 PR은 55개 테스트가 통과했다. HOUSE_TY 소수 표기를 유일하게 연결된 공식 모델에서만 추출하는 방향은 적절하다. 실제 응답에서 아크메르 동탄 99의 HOUSE_TY는 084.9916A, 공급면적 SUPLY_AR는 124.1106이다. 전용면적으로 사용하는 값은 84.9916이다.

초안의 기존 면적 대조 허용오차 0.02㎡는 서로 다른 공식 소수 면적을 통과시킬 수 있었다. 수치 표기의 정밀도 범위인 0.0001㎡를 넘는 충돌은 해당 주택형만 보류하도록 했다. 반경·거래 면적 허용폭 등 분석 정책은 변경하지 않았다. 잘못된 단일 주택형이 다른 검증된 주택형의 연결을 중단시키지 않는다.

- 산곡역자이힐스테이트의 `&`/`앤` 표기 차이와 인천계양 A6의 안내 문구·지구 표기를 정규화했다. 지번 또는 동일 사업지구·블록 근거가 함께 맞을 때만 확정한다.

## 좌표와 공급자 장애

아크메르 주소 뒤의 대괄호 부가표기가 카카오 정확 주소 대조를 막던 문제를 수정했다. 수원 주소 검색에서 다른 법정동도 반환되는 사례는 정확 일치 문서만 채택했다.

광명시 공고 제2024-2093호 A6블록 매각공고와 첨부 HWP를 확인했다. 확보한 텍스트에서 공식 지번 연결·WGS84 경계를 검증하지 못했으므로 A6 좌표를 생성하지 않았다. 출처: https://www.gm.go.kr/pt/user/nftcBbs/BD_selectNftcBbsDetail.do?q_nftcBbsCode=1003&q_nftcBbsMgtno=58199

공식 문서 해시, 검토시각, 사업번호·블록을 검증하는 지번 연결표/단순 폴리곤 대체 경로를 구현했다. 미검증 자료, 다른 사업, 비공식 출처, 좌표계 미확인 자료는 거부한다. `config/block-locations.json`은 비어 있으며 모의 좌표를 운영에 넣지 않았다.

브이월드는 API 인증·도메인 오류, 요청 형식 오류, HTTP 502 등 게이트웨이 오류, 연결 종료를 별도 분류한다. 현재 PC의 키 없는 요청은 HTTP 200/PARAM_REQUIRED였고, 기존 GitHub 인증 검사에서는 HTTP 502/RemoteDisconnected였다. 후자만으로 키 오류나 네트워크 차단을 확정할 수 없다. 카카오가 선택된 경우 브이월드에 의존하지 않는다. 인접 행정구역 조회 실패도 이미 검증된 대상 좌표를 무효화하지 않는다.

## 경기도 수집

기존 실행 로그는 `12:04:46 notice_stage_start` 후 `12:06:46 Notice stage failed`로 정확히 120초에 종료됐다. 마지막에만 저장하던 구조 때문에 그 실행의 신규 수집 내용이 사라졌다.

공고별 원자적 체크포인트, 80초 내부 예산, 요청별 짧은 제한, 강제 갱신 시 캐시·첨부 재사용 해제, 완료하지 못한 페이지·처리시각 기록을 추가했다. 다음 실행은 최신 페이지와 미완료 페이지를 우선하며 같은 공고만 반복하는 현상을 줄인다. 마지막 정상 시각은 실패 시 갱신하지 않는다.

실제 공개 게시판 검사에서 37개 게시물 처리 후 28개 공고를 보존한 저장을 확인했다. 캐시·재사용을 끈 별도 검사에서는 33개 게시물까지 중간 저장 후 `notice_budget_exhausted`로 정상 종료했다. 시간 초과로 전부 폐기하는 상태와 구분한다. 이미지 PDF 3개는 `document_text_missing`으로 남으며 OCR을 임의로 도입하지 않았다.

## 보안과 재현

승인된 증거 검사는 contents:read, 저장소 체크아웃 없음, 고정 inline Python으로만 실행했다. 인증키·전체 거래 응답은 출력하지 않는다. 국토부 검사는 집계와 단지당 최대 10건의 최소 거래 근거만 출력한다. PR 테스트에는 Secrets를 제공하지 않는다.

재현: `python -m pytest tests/backend -q`, `python -m scripts.compare_audit`. 모든 API 캡처는 공개 필드만 포함하며 관찰시각을 보존한다. 재현 시각을 실제 API 확인시각으로 바꾸지 않는다.

실제 연결 성공, 조회 범위 내 공식 정보 미확인, 추가 개발 필요를 구분하며, 샘플 통과를 운영 반영 완료로 취급하지 않는다.
