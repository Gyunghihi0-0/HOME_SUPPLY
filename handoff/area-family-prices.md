# 면적대 가격 범위 지원

동일 사업 검증은 기존 이름·지번/블록 기준을 유지한다. 정확한 주택형 매칭을 우선하며 실패한 경우 정수 면적대가 같은 모든 공식 모델의 LTTOT_TOP_AMOUNT로 범위를 만든다. 후보 하나라도 가격이 없으면 범위를 만들지 않는다.

- sale_price_basis: area_family_maximum
- sale_price_range_krw: 타입별 최고금액의 min/max. 전체 층별 최저/최고 가격이 아니다.
- price_candidate_types: 실제 비교한 공식 주택형 목록
- sale_price_krw: 범위 상단, 보수적 대표 계산 및 정렬용
- estimated_gap_range_krw: 비교 거래 중앙값 - 가격 범위의 역순. 분석 불가 시 null.
- 신뢰도 low 및 세부 타입 미확인 표시. 정확한 전용면적·배정물량·좌표·비교거래가 없으면 차익은 계산하지 않는다.

추가 필드는 선택 사항이며 기존 1.0.0 자료와 호환한다. docs/app.js는 원격 main의 기존 파일을 가져와 범위 표시와 타입 미확인 안내를 추가했다. 로컬에는 이전에 해당 파일이 없었다.

검증: 백엔드 58개 테스트 통과, Node 문법 검사 통과. 로컬 저장 자료와 공식 API 캡처 2026-10-18을 대조했을 때 동일 사업 연결 6개, 추가 면적대 fallback 후보 0개. 이는 신규 실조회나 운영 데이터 갱신이 아니다. 운영 배포는 수행하지 않았다. 단지 연결 실패를 개선하는 별도 작업이 필요하다.
